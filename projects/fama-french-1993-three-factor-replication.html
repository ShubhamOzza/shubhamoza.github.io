Replicating Fama & French (1993): Common Risk Factors in the Returns on Stocks and Bonds¶

The short version. Fama and French showed that three factors explain most of what makes stock portfolios move and what they earn on average:

  • the market,
  • a size factor (SMB, small minus big),
  • a value factor (HML, high minus low book-to-market).

I rebuilt their stock-side results for July 1963 – December 1991 from Ken French's data library, and the replication comes very close:

  • Sample. Exactly the paper's 342 months.
  • Factor premia. Within 0.02% a month of the paper's.
  • The 75 slopes in Table 6. Within 0.02 on average, correlating 0.97–1.00 with the paper's.
  • The intercepts. Their pattern is reproduced: 17 of the 25 three-factor intercepts are within 0.1% a month of zero (the paper: 16).

Getting there took one real fix. The paper's market return covers only the stocks in its 25 portfolios, not all of CRSP. Rebuilding it that way halved the gap in the size slopes. Running the same tests on the 416 months since 1992, the three-factor model still explains about 90% of the month-to-month variation. But the value premium has largely faded, and small growth stocks remain a large, unexplained anomaly.
Paper Eugene F. Fama and Kenneth R. French, Common Risk Factors in the Returns on Stocks and Bonds, Journal of Financial Economics 33(1), 1993, pp. 3–56

1. Data¶

Ken French publishes the factors and the 25 portfolios used in the paper, updated from the latest CRSP and Compustat files. The portfolios are formed exactly as in the paper:

  • each June, NYSE stocks set the breakpoints for five size groups and five book-to-market groups;
  • all NYSE, Amex and NASDAQ stocks are sorted into the 25 intersections;
  • value-weighted returns are computed from July to the following June.

One difference matters. In the paper, the market return RM is the value-weighted return on the stocks in the 25 portfolios (plus a small group with negative book equity). French's current market factor covers all CRSP stocks. The same file publishes each portfolio's number of firms and average firm size, so the paper's version can be rebuilt by weighting the 25 portfolio returns by their total market values.

FRENCH = "https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/ftp/"

def french_monthly(zip_name, table=None):
    # Ken French's CSV files hold several tables; by default read the first (monthly returns in percent)
    path = DATA / zip_name
    if not path.exists():
        path.write_bytes(requests.get(FRENCH + zip_name, timeout=120).content)
    zf = zipfile.ZipFile(path)
    lines = zf.read(zf.namelist()[0]).decode("latin1").splitlines()
    first = 0 if table is None else next(i for i, l in enumerate(lines) if table in l)
    start = next(i for i in range(first, len(lines)) if lines[i].startswith(","))
    rows = []
    for l in lines[start + 1:]:
        key = l.split(",")[0].strip()
        if not (len(key) == 6 and key.isdigit()):
            break
        rows.append(l)
    df = pd.read_csv(io.StringIO(lines[start] + "\n" + "\n".join(rows)), index_col=0)
    df.index = pd.PeriodIndex(df.index.astype(str), freq="M")
    return df.astype(float)

  • Standard deviations, lag-1 autocorrelations and correlations all match to within about 0.03. For example, the market–HML correlation is −0.36 against −0.38.
  • The 25 portfolios' average excess returns differ from the paper's by 0.04% a month on average, and the two sets correlate at 0.98. The paper's pattern is all there. In every size row, value stocks (high book-to-market) earn more than growth stocks (low), by 0.16–0.67% a month. The rise is steady except for a dip in size quintile 4, which the paper's data shows too. Small stocks earn more than big ones in most columns. The one outlier is the size-4/high-BE/ME portfolio, 0.17% lower than the paper's. A single cell standing out like that looks like a data revision in a handful of stocks rather than a construction difference.

Why aren't these identical? French's library is rebuilt every year from the latest CRSP and Compustat files, and both have been corrected and extended since 1993: missing delisting returns filled in, book values backfilled, firms reclassified. Small differences in which stocks fall into which portfolio in which year follow from that. They're too small to change any conclusion, but they mean "within a few hundredths" is the best a replication can achieve.

3. Table 6: the three-factor regressions¶

The heart of the paper is a time-series regression for each of the 25 portfolios:

$$R(t) - RF(t) = a + b\,[RM(t) - RF(t)] + s\,SMB(t) + h\,HML(t) + e(t)$$

The slopes b, s and h measure each portfolio's exposure to the market, size and value factors. If the factors capture what drives returns, the R² should be high, and the intercept a should be close to zero.

def ols(y, X):
    # OLS with an intercept; returns coefficients, t-stats, adjusted R^2 and residuals
    X1 = np.column_stack([np.ones(len(X)), X])
    beta, *_ = np.linalg.lstsq(X1, y, rcond=None)
    resid = y - X1 @ beta
    n, k = X1.shape
    s2 = resid.T @ resid / (n - k) if resid.ndim == 1 else (resid ** 2).sum(axis=0) / (n - k)
    cov_diag = np.diag(np.linalg.inv(X1.T @ X1))
    se = np.sqrt(np.outer(cov_diag, s2)) if resid.ndim > 1 else np.sqrt(cov_diag * s2)
    tss = ((y - y.mean(axis=0)) ** 2).sum(axis=0)
    r2_adj = 1 - (resid ** 2).sum(axis=0) / (n - k) / (tss / (n - 1))
    return beta, beta / se, r2_adj, resid


def three_factor(excess, fac, market="RM-RF"):
    beta, t, r2, resid = ols(excess.values, fac[[market, "SMB", "HML"]].values)
    out = {name: grid(beta[i]) for i, name in enumerate(["a", "b", "s", "h"])}
    out.update({f"t({name})": grid(t[i]) for i, name in enumerate(["a", "b", "s", "h"])})
    out["R2"] = grid(r2)
    out["resid"] = resid
    return out

The slopes match closely. The mean absolute gap from the paper is 0.02 for b, s and h alike, and the R² values are within 0.01 on average. The scatter plots sit on the 45-degree line. The economics is identical:

  • Size slopes s fall steadily from about 1.4 for the smallest stocks to slightly negative for the biggest.
  • Value slopes h rise from about −0.4 for growth stocks (low book-to-market) to about +0.7 for value stocks, in every size row.
  • Market slopes b are all close to 1, which is why, as the paper stresses, the market factor alone can't explain why average returns differ so much across these portfolios.
  • R² is 0.83 to 0.97. Three factors capture almost all the month-to-month movement of 25 diversified portfolios.

The summary table also shows the effect of the market definition. With French's all-CRSP market factor, the size slopes are systematically 0.04 lower than the paper's. With the market rebuilt from the 25 portfolios as the paper defines it, that bias falls to 0.01, while b and h are essentially unaffected. That's the one place where matching the paper required changing the model rather than just running it, and the change follows the paper's own definition rather than a tuning choice.

4. The intercepts: does the model explain average returns?¶

High R² says the factors explain the variation in returns. The tougher test is the intercepts. If the three factors fully explain average returns, every a should be zero. The paper compares three models (Tables 9a and 9b):

  • the CAPM, with the market alone;
  • SMB and HML without the market;
  • all three factors together.

5. Beyond the paper's tables: testing all 25 intercepts at once¶

Looking at intercepts one at a time doesn't say whether, taken together, they're further from zero than chance would allow. The Gibbons–Ross–Shanken (GRS) test (1989) answers exactly that. It's an F-test that all 25 intercepts are jointly zero, which takes into account that the portfolios' errors are correlated. The paper's own F-test (Table 9c) pools the stock and bond regressions, so it can't be compared directly. Here it's applied to the 25 stock portfolios alone.

In [9]:
def grs(excess, fac_cols, fac):
    # Gibbons-Ross-Shanken test that all intercepts are jointly zero
    X = fac[fac_cols].values
    beta, _, _, resid = ols(excess.values, X)
    T, N, L = len(excess), excess.shape[1], X.shape[1]
    a = beta[0]
    sigma = resid.T @ resid / (T - L - 1)
    mu = X.mean(axis=0)
    omega = np.cov(X, rowvar=False, ddof=1).reshape(L, L)
    stat = (T / N) * ((T - N - L) / (T - L - 1)) * (a @ np.linalg.solve(sigma, a)) / (1 + mu @ np.linalg.solve(omega, mu))
    return stat, f_dist.sf(stat, N, T - N - L)

The model's two jobs come out very differently after 1991.

  • Explaining variation still works. The three factors explain about 90% of the monthly variation of the 25 portfolios (average R² 0.90, against 0.93 in the paper's period). As a risk model, a description of what moves portfolios together, it has held up for 35 years.
  • Explaining average returns works less well.
    • The GRS test now rejects the three-factor model (F = 3.63, p < 0.001) as firmly as the CAPM.
    • The average absolute intercept rises from 0.09% to 0.12% a month.
    • Small growth stocks are the outlier again, at −0.57% a month: the same anomaly, larger.
  • The premiums themselves have changed. The market premium was strong (0.77% a month, t = 3.65). SMB averaged just 0.06% (t = 0.36), so the size premium has essentially vanished. HML averaged 0.23% (t = 1.40), below its 1963–91 level and no longer reliably positive. Its 10-year rolling average peaked at 0.67% a month in 2001 and was negative by 2021, the well-known "death of value" decade.

None of this contradicts the paper. It explains its sample very well. It does show the difference between a model that describes risk and a set of premiums you can count on earning, and why later work added more factors (momentum, profitability, investment).

7. Do the numbers make sense?¶

  • The sample is exactly the paper's 342 months, and the factor statistics match to within 0.02% a month.
  • The slopes behave as they must. Size slopes fall with size and value slopes rise with book-to-market, with no exceptions. Market slopes are all near 1, as they should be for diversified stock portfolios.
  • R² values of 0.83–0.97 are plausible. Diversified portfolios have little idiosyncratic noise left, so a good factor model should explain most of their variation.
  • The intercept patterns are economically sensible. The CAPM fails on value stocks (positive alphas) and growth stocks (negative alphas); a model without the market leaves the equity premium in every intercept.
  • The remaining gaps are small and unsystematic, except for the market-definition effect on s, which was identified and fixed. They're consistent with revisions to CRSP and Compustat since 1993.

8. Is the procedure right?¶

  • Each regression is ordinary least squares on 342 monthly observations, exactly as in the paper. R² is adjusted for degrees of freedom, as the paper's footnote says.
  • The market factor is built as the paper defines it, from the 25 portfolios, using start-of-month market values so that nothing uses information from later in the month. French's all-CRSP version is reported alongside for comparison.
  • The comparisons are against the paper's printed values, typed in as targets. No number in the replication is set from the paper.
  • The out-of-sample test uses exactly the same code and definitions, with no changes after looking at the later data.

Wrapping up¶

This is a close replication. Every table on the stock side of the paper comes back to within a few hundredths, and the factor slopes match to 0.02. The headline result reproduces with the same cells standing out: the CAPM fails on size and value, and the three-factor model's intercepts are near zero except for small growth stocks. The one structural difference, the definition of the market return, was found by testing a specific hypothesis, and fixing it brought the size slopes into line.

Thirty-five more years of data split the paper's claims in two. The three factors still describe how stock portfolios move together, but the average premiums for size and value have been much weaker. The model's success at explaining average returns was partly a feature of its sample.
